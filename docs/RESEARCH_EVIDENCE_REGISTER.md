## Claim-handling rules

- `FACT` — cite dated public source.
- `EXTERNAL-GEOGRAPHY` — use for transferable operational evidence but never call it Rajasthan field performance.
- `DEMO` — visually label “evaluator scenario / synthetic demo data”.
- `PREDICTION` — label model output and explain input assumptions.
- `PILOT TARGET` — label proposed target, never achieved result.
- `LIVE_PUBLIC` — only a genuinely reachable public source (currently IMD gateway).
- `AUTH_REQUIRED` / `CONTRACT_DEFINED` / `ADAPTER_READY` — no fake privileged Government connectivity.
- `POLICY` — support/eligibility values are Department-configured; demo rates are illustrative.
- `AGRONOMY` — no universal yield benefit is promised; outcomes are measured per crop/service/pilot.
