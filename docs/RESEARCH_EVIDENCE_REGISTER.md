## Claim-handling rules

- **Fact:** cite the dated public source.
- **Pilot target:** label “proposed target”, never present as achieved.
- **Dashboard count/cost:** label “evaluator scenario / synthetic demo data”.
- **Integration:** display actual maturity (`LIVE_PUBLIC`, `ADAPTER_READY`, `CONTRACT_DEFINED`, `AUTH_REQUIRED`, etc.).
- **Policy:** any support rate or service eligibility is Department-configured; demo values are illustrative.
- **Agronomy:** no universal yield benefit is claimed. Outcomes are measured per crop/service/pilot design.
